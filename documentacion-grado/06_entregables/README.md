# Entregables académicos

Esta carpeta separa los dos documentos que se presentan durante el proceso de titulación:

- [`perfil/PERFIL_PROYECTO_GRADO.md`](perfil/PERFIL_PROYECTO_GRADO.md) — perfil oficial completo en contenido Markdown, pendiente de revisión de la tutora y maquetación posterior.
- [`proyecto_grado/01_capitulo_marco_introductorio.md`](proyecto_grado/01_capitulo_marco_introductorio.md) — primera versión del Capítulo I.
- [`proyecto_grado/02_capitulo_marco_teorico_conceptual.md`](proyecto_grado/02_capitulo_marco_teorico_conceptual.md) — estructura y desarrollo inicial del Capítulo II, incluidas las bases de RUP, SDD y asistencia de IA.

El Markdown es la fuente de contenido. El destino de trabajo y presentación del Perfil será el **Google Docs existente en Drive**, al que se transferirán directamente las versiones aprobadas. No se utilizará el DOCX local ni un proceso basado en `.tmp` como intermediario.

Toda tabla incorporada al Perfil o al documento final deberá llevar inmediatamente debajo una nota de procedencia. Si es de elaboración propia, la nota identificará también las fuentes bibliográficas, los datos, las secciones o las decisiones que sirvieron de base, conforme a los [`criterios editoriales`](../01_lineamientos/criterios_editoriales_proyecto_grado.md#91-fuentes-de-las-tablas).

Los lineamientos, planes, investigación, metodología y recursos que sustentan estos entregables permanecen en las carpetas `01` a `05`; no deben duplicarse aquí salvo que formen parte del texto entregable.
