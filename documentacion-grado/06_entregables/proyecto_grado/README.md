Hasta la aprobación del perfil, la fuente oficial del alcance, los objetivos y el diseño de evaluación es [`../perfil/PERFIL_PROYECTO_GRADO.md`](../perfil/PERFIL_PROYECTO_GRADO.md). 2. **investigación y evaluación:** fuente o participante → instrumento → dato → análisis → resultado → conclusión.
