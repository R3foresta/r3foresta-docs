# Proyecto de Grado — documento final

Espacio reservado para el documento universitario final de R3Foresta. Su redacción debe partir del perfil aprobado y de la evidencia generada durante el diagnóstico, desarrollo, verificación técnica y evaluación operativa.

## Estructura prevista

1. Marco introductorio y aspectos generales.
2. Marco teórico.
3. Marco aplicativo o práctico.
4. Verificación y evaluación de resultados.
5. Conclusiones y recomendaciones.
6. Bibliografía y anexos.

Hasta la aprobación del perfil, la fuente oficial del alcance, los objetivos y el diseño de evaluación es [`../perfil/PERFIL_PROYECTO_GRADO.md`](../perfil/PERFIL_PROYECTO_GRADO.md). La ejecución posterior se controla en [`../../02_planificacion/TODO_PROYECTO_GRADO.md`](../../02_planificacion/TODO_PROYECTO_GRADO.md), sin mezclarla con el TODO de cierre del perfil.

El documento final deberá presentar dos cadenas de evidencia relacionadas:

1. **construcción académica:** línea base limpia → incremento por sprint → pruebas críticas → demostración;
2. **investigación y evaluación:** fuente o participante → instrumento → dato → análisis → resultado → conclusión.
