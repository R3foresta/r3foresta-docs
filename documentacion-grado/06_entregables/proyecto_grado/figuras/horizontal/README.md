# Antecedente horizontal del Capítulo III

> Sustituido por la corrección del autor del 16 de noviembre de 2026. Usar las [láminas carta verticales vigentes](../paginas/README.md) para maquetar. Este directorio conserva la entrega horizontal anterior y sus fuentes.

Las fuentes se encuentran en los bloques Mermaid de cada fase y en [las copias editables](../mermaid/). Las láminas miden 2400 × 1500 y repiten participantes o entidades entre paneles para conservar la continuidad. Las fuentes completas de secuencia y relaciones también se incluyen abajo; algunas son verticales por la cantidad de mensajes o relaciones. Antes de insertar en el documento final, comprobar legibilidad y dimensiones de impresión.

Después de renderizar una fuente de panel, `python3 componer-laminas.py` recompone las láminas desde los SVG y el [manifiesto de grupos](paneles/grupos.json). Estos derivados deben regenerarse cuando cambie el diagrama completo. Los diagramas conceptual, lógico y físico resumidos se consultan por separado en [modelos de datos](../modelos-datos/README.md).
